# Auréa Spa & Wellness

A premium animated spa homepage built with Next.js, React and Tailwind CSS.

## Start the project

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Add the hero video

1. Export an H.264 MP4, ideally 8–15 seconds and under 5–7 MB.
2. Rename it to `aurea-spa-hero.mp4`.
3. Place it inside `public/videos/`.

The current massage photograph is configured as the poster fallback, so it
remains visible while the video loads or when autoplay is unavailable.

## Deploy

Push the project to GitHub and import the repository into Vercel. No environment
variables are required for the demo.
